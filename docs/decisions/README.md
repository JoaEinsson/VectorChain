# Registros de decisão arquitetural

ADRs preservam decisões que afetam matemática, causalidade, APIs, experimentos ou dependências.

Estados permitidos: `Proposed`, `Accepted`, `Superseded` e `Rejected`.

Nomeie arquivos como `NNNN-titulo-curto.md` e use:

```text
# NNNN — Título
Status: Proposed
Data: YYYY-MM-DD

## Contexto
## Decisão
## Consequências
## Alternativas consideradas
```

Um ADR aceito não é editado para reescrever a história. Uma decisão posterior cria um novo ADR e
marca o anterior como substituído.
